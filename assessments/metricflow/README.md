# MetricFlow Assessment

MetricFlow is a fictional Tier 1 cloud analytics vendor in this project. The vendor processes customer PII and confidential analytics data, connects through a production API and service account, and supports critical reporting workflows.

- [Vendor Risk Assessment](../../reports/MetricFlow_Vendor_Risk_Assessment.pdf)
- [SOC 2 Review](../../reports/MetricFlow_SOC2_Review.pdf)
- [DR Test Summary](../../evidence/metricflow/MetricFlow_DR_Test_Summary.pdf)
- [Penetration Test Summary](../../evidence/metricflow/MetricFlow_Penetration_Test_Summary.pdf)
- [Access Control Policy Excerpt](../../evidence/metricflow/MetricFlow_Access_Control_Policy_Excerpt.pdf)
- [TPRM Assessment Workbook](../../TPRM_Vendor_Risk_Assessment.xlsx)

The assessment recommendation is **Approve with Conditions**. The workbook contains the scoring model, questionnaire responses, evidence review, risk register, remediation tracking, and monitoring records.

All vendor names, evidence, findings, dates, and decisions in this scenario are fictional and created for portfolio use.
